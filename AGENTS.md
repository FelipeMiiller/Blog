# Next.js 16

Este projeto usa Next.js 16. Antes de alterar rotas, APIs do App Router, cache, metadata ou configuração, consulte a documentação da versão instalada em `node_modules/next/dist/docs/`.

As APIs de request, incluindo `params`, `searchParams`, `cookies()` e `headers()`, devem ser tratadas de forma assíncrona. O lint é executado pela CLI do ESLint usando `eslint.config.mjs`; `next lint` não está disponível nesta versão.
